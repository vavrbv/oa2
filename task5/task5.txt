Система модулей и пакетов Python напрямую поддерживает пункты 2, 3 и 5.
В рамках модуля Python можно создавать функции, которые будут обращаться к другим
функциям в этом модуле. Модули могут быть объединены в пакеты и загружаться
в программу как всем пакетом целиком: import package, так и отдельно, используя
имя пакета как префикс: import package.module. Модуль может импортировать
другой модуль или пакет и обращаться к определённым в нём объектам
(функции, классы, переменные).
Прямой поддержки пунктов 1, 4 в Python нет. Поддержка параметризацим типами
доступна для функций и классов. Однако, с помощью модуля importlib доступна
функция import_module, которая предоставляет воможность динамической загрузки
модулей по имени. Таким образом, определяя некоторый родительский модуль
можно определить модуль-потомок, переопределяющий переменные, функции, классы
родительского и с помощью import_module динамически подгружать модуль с нужной
реализацией. Однако это всё ещё требует от пользователя самостоятельного
выбора нужной реализации.
